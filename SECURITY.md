# Security

Report vulnerabilities privately to **contact@darrenis.top**. Do not post API keys, cookies, private posts or exploitable vulnerabilities in public issues.

Include the extension version, Chrome version, affected platform, impact and minimal reproduction. Use synthetic data and redact credentials. The current 0.4.x series receives security fixes. Site DOM changes and upstream API errors should be reported as ordinary bugs unless they expose data or create a security vulnerability.
